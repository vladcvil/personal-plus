# BPMN-моделі бізнес-процесів компанії «Персонал+»

## Використаний інструмент
* **Редактор:** diagrams.net (draw.io)
* **Нотація:** BPMN 2.0 (бібліотека фігур BPMN 2.0 General, Tasks, Events, Gateways)

## Склад моделей
1. `01_hiring.drawio` / `01_hiring.pdf` — процес «Найм працівника»
2. `02_leave.drawio` / `02_leave.pdf` — процес «Подання й погодження відпустки»
3. `03_timesheet.drawio` / `03_timesheet.pdf` — процес «Облік робочого часу (табель)»
4. `04_offboarding.drawio` / `04_offboarding.pdf` — процес «Звільнення (offboarding)»

## Як відкрити вихідні файли (.drawio)
1. Відкрийте веб-редактор [app.diagrams.net](https://app.diagrams.net/).
2. У верхньому меню оберіть `File` → `Open from` → `Device` (або просто перетягніть відповідний `.drawio` файл у вікно браузера).

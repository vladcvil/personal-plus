# Проєкт «Персонал+» — Відділ забезпечення якості (QA)

Репозиторій команди із супроводу та забезпечення якості хмарної HRM-системи **«Персонал+»** в рамках дисципліни *«Технології забезпечення якості програмних засобів»*.

* **Продукт:** №3 «Персонал+» (HRM-система)
* **Demo-стенд:** [OrangeHRM Demo](https://opensource-demo.orangehrmlive.com)
* **Стек технологій продукту:** PHP (Symfony), Vue.js, MySQL

## Вимоги до середовища
* **JDK 17** (Temurin)
* **Maven 3.9**
* **Chrome** або **Firefox** (драйвер підтягується автоматично через Selenium Manager)
* Залежності: **JUnit 5 (5.10.2)**, **Selenium 4 (4.21.0)** — підтягуються автоматично з `pom.xml`.

## Як зібрати і запустити тести

Клонуйте репозиторій та виконайте в терміналі з кореня проєкту (там, де лежить `pom.xml`):

```bash
git clone https://github.com/vladcvil/personal-plus.git
cd personal-plus

# Запустити всі тести (юніт + UI з тегом ui)
mvn test -DexcludedGroups=none

# Запустити лише юніт-тести бізнес-логіки
mvn test -Dtest='*Test'

# Запустити лише UI-сценарії WebDriver
mvn test -Dtest='*UiTest'
